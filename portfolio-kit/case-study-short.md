# WordPress Archive - Short Case Study (Portfolio Version)

I built WordPress Archive to solve a common problem: theme/plugin discovery is usually overwhelming and slow. Most directories are static lists, so users do too much manual comparison.

To improve this, I designed a recommendation-driven full-stack app using React, Express, and PostgreSQL. I added curated collections (Hidden Gems, Heavy Hitters, Fresh Finds), a Recommendation Radar, goal-based Stack Builder, Compare Bench, Favorites Vault, and shareable snapshots. Each item card also includes a one-click WP-CLI copy action so users can move from discovery to implementation immediately.

On the engineering side, I treated it like a production product: integration tests (Jest + Supertest), frontend/backend CI, branch protection, release automation, Docker support, and security/dependency governance.

This project showcases both product thinking and software engineering depth: UX strategy, API design, scoring logic, testability, and delivery workflows.
