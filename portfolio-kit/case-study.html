WordPress Archive

A recommendation-driven discovery platform for WordPress themes and plugins, built to reduce decision fatigue and speed up practical implementation.

React Express PostgreSQL Recommendation Scoring CI + Tests
View Repository

Problem

Directory-style browsing makes plugin/theme selection slow and overwhelming. Users need guided decision support, not endless lists.

Solution

Built product workflows: Recommendation Radar, Discovery Lab collections, Stack Builder by goal, Compare Bench, Favorites Vault, and shareable snapshots.

Key Product Features

  • Recommendation score blending quality, popularity, freshness
  • Goal-based stack generation (SEO, ecommerce, performance, security)
  • One-click WP-CLI copy actions on each card
  • Share links for favorites and comparison state

Engineering Depth

  • Backend/frontend CI pipelines
  • Integration tests with Jest + Supertest
  • Branch protection + CODEOWNERS
  • Release workflow and security automation
  • Docker + deploy configs (Render/Vercel)

Portfolio Narrative

This project demonstrates product thinking plus production engineering: I translated a discovery pain point into a full-stack, recommendation-based experience with measurable UX value and maintainable operational workflows.
