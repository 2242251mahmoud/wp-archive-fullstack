# Portfolio Snippets - WordPress Archive

## 1-Line Project Summary
Built a full-stack WordPress discovery platform with recommendation scoring, stack generation, compare workflows, and production-grade CI/security automation.

## Short Description (Website Card)
WordPress Archive is a full-stack discovery app for WordPress themes and plugins. It combines smart recommendations, curated collections, and side-by-side comparison to help users choose tools faster.

## Medium Description (Project Page)
I designed and built WordPress Archive as a portfolio-grade product that goes beyond basic CRUD. The app includes a recommendation engine (quality + popularity + freshness), a goal-based stack builder, compare bench, favorites vault, shareable snapshots, and WP-CLI quick actions. On the engineering side, I implemented backend/frontend CI workflows, endpoint integration tests, branch protection, security automation, and deployment-ready configs for Render and Vercel.

## Resume Bullets
- Architected and shipped a full-stack discovery platform (React, Express, PostgreSQL) with a recommendation scoring model and guided stack generation.
- Implemented product-level UX features (compare bench, favorites vault, share snapshots, WP-CLI quick actions) to improve decision speed and usability.
- Built production-grade workflows: CI pipelines, integration tests, branch protection, release automation, and dependency/security governance.

## Feature Highlights
- Discovery Lab collections (Hidden Gems, Heavy Hitters, Fresh Finds)
- Recommendation Radar
- Build My Stack (goal-based curation)
- Compare Bench (side-by-side evaluation)
- Favorites Vault (persisted state)
- Share Snapshot links
- WP-CLI copy actions
